# Item Properties & Schema Reference

This document is a comprehensive, single-source reference for all JSON properties, types, and options supported by the homebrew schema for items, weapons, and tools.

It combines information from:

- [item-conversion.md](./item-conversion.md)
- [tool-conversion.md](./tool-conversion.md)
- [weapon-conversion.md](./weapon-conversion.md)
- [Spec_Copy.md](./Spec_Copy.md)
- The official `brew-fast` schema files (`items.json`, `util.json`, etc.)
