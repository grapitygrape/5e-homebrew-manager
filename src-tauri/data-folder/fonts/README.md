# fonts

Licensed fonts for the app and the site. They can't ship with the app or be
committed to a repo, so put your own copies here. The file names must match.

| File | Used for |
| --- | --- |
| `modesto-condensed.woff2` | Headings in this app, the Site theme module and the reskin. Titles in the reskin when Majesty is missing. |
| `modesto-condensed-bold.woff2` | Bold headings in this app. |
| `majesty-bold.woff2`, `majesty-black.woff2` | Titles in the reskin. |

When a font is missing, Nodesto Caps Condensed is used instead. It ships with
the app (CC BY-SA 4.0, by Solbera), so you don't need to add it here.
